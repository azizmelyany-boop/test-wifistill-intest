# ⚡ Wi-Fi Diagnostic & Speed Analyzer Tool

A lightweight, modern HTML5/JavaScript web application designed to test internet speeds, measure bufferbloat/latency, detect Wi-Fi interference, and provide actionable steps to fix slow home networks.

## 🔥 Key Features

- **Real-Time Speed Test Engine:** Measures Download, Upload, Ping Latency, Jitter, and Packet Loss using standard fetch streaming API calls.
- **Bufferbloat & Health Score:** Grades traffic queuing under load (A+ to F) and calculates an overall network health rating (0–100).
- **Wi-Fi Spectrum Visualizer:** Interactive HTML5 Canvas chart displaying 2.4 GHz and 5 GHz channel congestion and overlap.
- **Automated Issue Detection:** Pins down specific network problems like bufferbloat lag, signal attenuation, DNS delay, and channel interference.
- **Actionable Fix Guides:** Provides clear, step-by-step instructions to optimize router settings (QoS/SQM, channel switching, custom DNS).
- **Monetization Ready:** Built-in slots for ad units, affiliate product links (routers, cables), and support buttons.
